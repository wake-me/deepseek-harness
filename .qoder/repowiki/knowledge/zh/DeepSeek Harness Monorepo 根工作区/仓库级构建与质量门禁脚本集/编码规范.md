- 每个 gate 同时提供 `xxx.ts` 实现与 `xxx.spec.ts` 测试，测试通过 Vitest 在仓库内直接运行，不依赖编译产物。
- gate 通过 `pnpmScript` / `pnpmExec` 包装成 `Gate` 对象声明 id、label、command、args、needs、env、allowFailure，由 `run-gates` 统一调度而非各自 fork 子进程。
- 需要跨文件类型信息的脚本统一使用 `ts-project.ts` 的 `TypeScriptProject` 加载扁平化的 tsconfig host graph，避免重复构造 Program。
- 仓库路径一律以 `/` 分隔的相对路径表示，并在入口处用 `resolve(import.meta.dirname, '..')` 定位仓库根，保证脚本可在任意 cwd 下运行。
- 可配置开关通过 `process.env` 布尔标志（如 `DSH_*_SKIP_*`、`*_USE_*`）控制行为分支，并以 `flagEnabled` / `positiveIntArg` 等函数集中解析与校验。
- 对 Markdown 生成的区域采用 `<!-- BEGIN GENERATED <slug> -->` / `<!-- END GENERATED <slug> -->` 标记，并由 `partitionGeneratedRegions` 严格匹配 slug 后剥离再生成内容。
