模块以 `native/landlock-run/` 为独立 pnpm workspace，采用「入口 JS + 多平台预编译二进制」的三包拆分：
- `packages/entry`（`@deepseek-ai/node-addon-landlock-run`）：暴露 `launcherPath()`、`grantArgs()`、`probe()` 三个导出，封装对 CLI 契约（`docs/cli-contract.md`）的实现；通过 `os/cpu` optionalDependencies 解析对应平台包中的 `bin/landlock-run` 并 `spawnSync` 调用。
- `packages/linux-x64` / `packages/linux-arm64`：仅声明 `os: [linux]` + `cpu` 字段，内含 `prebuilds.json` 矩阵和打包后的 `bin/landlock-run` 静态二进制，由 `scripts/build.ts` 在 CI 各架构 runner 上用 `musl-gcc -static` 构建，不依赖宿主 glibc。
- `scripts/`：构建、发布、验证脚本集中管理 prebuilds 组装、版本 bump、tarball 打包与安装验证；`test/` 用 Node 直接运行 JS 测试覆盖入口与 launcher 行为。
依赖方向单向：entry → 平台包（optionalDependency）→ 二进制；JS 层不解析 launcher 输出细节，只消费 `--probe` 返回的 `full/partial/unusable` 判定与固定退出码 `125`，从而将 ABI 漂移限制在 package family 内部。
