- 新增文档页面通过在 `docs.ts` 中以 `pairedPages` 或 `mirroredPages` 描述符注册，统一声明 source、route、label、sidebar、section、order 字段，而非手写 VitePress 路由。
- 中英文双语页面成对维护，中文源文件以 `.zh.md` 后缀命名，英文源文件以 `.md` 命名，通过 `pairedPages` 自动展开为两个 locale 的 DocsPage。
- 侧边栏分组顺序与折叠状态集中在 `sections` 记录中声明，页面仅引用 `section` 标签，由 `sectionSpec` 校验其存在性并计算排序索引。
- 导航项与侧边栏条目共享同一份集合元数据（guideModules、moduleNav），避免硬编码重复的路径与 label。
- Markdown 内容中的 Vue 插值语法 `{{ }}` 会在渲染阶段被转义为 HTML 实体，防止 VitePress/Vue 将其误解析为模板表达式。
