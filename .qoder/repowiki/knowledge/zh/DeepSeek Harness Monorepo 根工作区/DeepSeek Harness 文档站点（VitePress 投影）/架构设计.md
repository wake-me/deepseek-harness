站点由三个核心部分组成：`package.json` 定义 VitePress 1.6 及 mermaid、cytoscape 等依赖与 dev/build/preview 脚本；`.vitepress/config.ts` 是站点入口，使用 `withMermaid` 包装配置，设置双 locale（root 简体中文、en 英文），并通过 `srcDir: '.generated'` 指向由外部脚本生成的源码树，同时注入自定义 CSS（wordmark、滚动条样式）和监听 canonical docs 变更的 Vite 插件以在开发时重新运行 `projectDocs()`；`docs.ts` 是唯一的“发布清单”，集中声明所有页面（homeAndGuide、develop、cordisTutorial、subsystemsReference、reference 等），通过 `pairedPages` / `mirroredPages` 辅助函数将每篇中文源映射到 zh-CN 路由、英文源映射到 en-US 路由，缺失翻译时回退到可用语言，并按 `sections` 定义的分组顺序生成侧边栏与导航链接。依赖方向单向：config.ts → docs.ts → 外部 `scripts/project-doc-site.ts`（负责把 `docs/` 下的 Markdown 复制到 `.generated/` 并写入 frontmatter），网站本身不直接读写源 Markdown。
