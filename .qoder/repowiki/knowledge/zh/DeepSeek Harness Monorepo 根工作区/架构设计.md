根目录作为 monorepo 编排层，通过 pnpm-workspace.yaml 声明 vendor/*、packages/*/*、native/landlock-run、apps/*、website、examples、python/sdk-runtime 等工作区成员，并以 linkWorkspacePackages + overrides 将 @deepseek-ai/cosmokit/schemastery 等上游框架指向本地 vendor 源码，保证所有子包共享同一份依赖图。

- 构建编排：package.json 的 build:lib/host/client 通过 TypeScript project references（tsconfig.host.json / tsconfig.client.json）分别编译宿主与客户端产物，再由 tsdown 打包；build:web 委派给 apps_web 的 Vite 构建。
- 类型解析门面：tsconfig.base.json 集中维护 @deepseek-ai/dsh-* 到 packages/*/src 的路径映射以及 vendor/* 别名，使各子包以统一 npm 风格 import 彼此，新增包无需改路径表。
- 测试编排：vitest.shared.ts 提供装饰器预转换与 webstorage 标志，根级 vitest.*.config.ts 按场景（unit/e2e/web/perf/stress/snapshot）复用该共享配置，scripts/run-gates.ts 串联 check-all / ci-* 门禁。
- 插件装配契约：apps_cli 作为 dsh 入口，通过 Cordis Loader 在启动时加载 core/boot/host/util 等子包暴露的插件，再组合 session lifecycle、agent flow、tools/skills、storage、infrastructure、user interaction、client SDK、extensions 等能力族形成完整应用；native_sandbox 以 @deepseek-ai/node-addon-landlock-run 被 host 侧调用。
- 质量与发布：scripts_build 下的 run-gates.ts、publint、knip、jscpd、oxlint、release/* 等脚本由根 scripts 统一调度，docs 与 website_docs_site 通过清单把 Markdown 投影为站点并校验引用。
