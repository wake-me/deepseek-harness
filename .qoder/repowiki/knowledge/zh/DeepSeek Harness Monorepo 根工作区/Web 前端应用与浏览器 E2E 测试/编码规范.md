- 每个 E2E 场景以 `<feature>.e2e.ts` 命名，并在 `tests/snapshots/<feature>/` 下放置对应的 `.expected.md` / `.jsonl` / `.override.json` 黄金文件，测试断言与快照一一对应。
- 需要覆盖默认会话配置的测试通过同目录的 `<feature>.overlay.yml` 提供补丁，而非修改共享 scaffold。
- 测试文件不直接 import `@deepseek-ai/dsh-client-*` 值或类型，而是将所需常量/纯函数镜像到本地（如欢迎通知文案），以便在 Host tsconfig.host.json 下编译而不污染 Client 构建图。
- 构建期重型第三方库通过 `VENDOR_PACKAGES` 白名单显式抽离为 vendor chunk，React-free 约束确保 React 不被误拉入 vendor。
- 对 Node-only 模块（如 `node:module`）使用 `vite.resolve.alias` 映射到 `src/node-module-stub.ts` 中的抛出实现，保证浏览器环境无法误用。
