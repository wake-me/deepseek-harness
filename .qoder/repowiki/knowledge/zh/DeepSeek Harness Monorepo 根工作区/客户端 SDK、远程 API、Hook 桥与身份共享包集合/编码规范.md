- 每个子包采用统一目录布局：`src/` 源码、`tests/` 测试、`package.json`、`tsconfig.json`、`README.i18n.yaml`、`tsdown.config.ts`，便于独立发布与构建。
- 跨包通信通过 TypeScript 类型契约与 Cordis 上下文键（如 `ctx.typertGateway`、`ctx.remote`、`ctx.remote`）注入，避免直接导入具体实现，保持依赖方向单向。
- UI 功能以 `ui-*` 命名作为可插拔插件，通过 `ui-slots/` 定义的插槽系统进行注册与组合，而非硬编码引用。
- 每个包内包含 `invariant.ts` 文件集中存放运行时不变量断言，并在多处业务逻辑中复用。
- 支持双宿主编译的包（如 `client/connection`、`api/gateway`、`api/remotes`）通过 `tsconfig.client.json` 与 `tsconfig.host.json` 分离客户端与宿主代码路径。
- 对外暴露的公共 API 集中在包的 `index.ts`，内部实现按职责拆分到多个源文件，测试文件与源码一一对应放置于 `tests/`。
