本模块由五个并列的子目录组成，每个子目录都是一个独立的 npm 包集合，通过 Cordis 服务注入与 TypeScript 类型契约相互协作：
- `packages/client/`：浏览器端产品包集合（`@deepseek-ai/dsh-client-*`），按职责拆分为 shell 启动 (`web/`)、模块加载 (`modules/`)、React 渲染连接 (`web-react/`)、浏览器-Host RPC (`connection/`)、共享运行时服务 (`runtime/`)、HMR (`hmr/`)、国际化 (`locale/`)、Schema 表单 (`schema-form/`)，以及大量以 `ui-*` 命名的 UI 功能插件（conversation、workspace、settings、tool、workflow-run 等）。所有 UI 插件通过 `ui-slots/` 定义的插槽系统注册并组合，依赖方向自底向上：ui-primitives → ui-* → web/web-react。
- `packages/sdk/`：驱动 Harness 运行时的进程间协议栈，分三层——`protocol/` 定义 wire protocol（transport + types），`client/` 提供调用方 API，`server/` 在 Host 侧以 stdio JSON-RPC 暴露服务端；三者通过纯类型契约解耦，不感知具体宿主。
- `packages/api/`：面向应用的 Remote 层，`remotes/` 实现 BFF 策略（Agent/Session 查找、Client Remote 贡献组装），`gateway/` 实现 Typert 单向 RPC 端点；依赖方向严格为 `remotes → gateway → connection → webserver`，通过 `ctx.typertGateway` / `ctx.remote` 注入而非直接导入。
- `packages/hooks/`：将外部 Shell Hook（Claude Code、Codex）翻译为 Harness 拦截扩展点的桥接插件，`hook-protocol/` 提供共享编解码、匹配器、事件合并与 runner，各 `hooks-*` 包仅负责各自方言的事件映射。
- `packages/identity/`：极轻量共享库，仅提供 `anonymous-user-id/` 用于持久化匿名关联 ID，供遥测、反馈与 DeepSeek 请求使用，不表示已认证账户。
所有子包均遵循统一的单包结构：`src/` + `tests/` + `package.json` + `tsconfig.json` + `README.i18n.yaml` + `tsdown.config.ts`，并通过 tsdown 构建产物。
