- 每个 package 在 `src/invariant.ts` 注册自身不变量，并由 `runtime-diagnostics/invariants` 在运行时校验
- 对外暴露的能力以 tool/command/service 形式挂载到 `ctx`，而非直接耦合调用
- 类型定义集中在 `src/types.ts`，不包含运行时代码
- 测试统一放在 package 根下的 `tests/` 目录，并按 invariant.spec.ts、integration.spec.ts 等命名组织
- README 使用 README.md + README.zh.md + README.i18n.yaml 三件套，按 Model Experience 格式描述模型可见行为
