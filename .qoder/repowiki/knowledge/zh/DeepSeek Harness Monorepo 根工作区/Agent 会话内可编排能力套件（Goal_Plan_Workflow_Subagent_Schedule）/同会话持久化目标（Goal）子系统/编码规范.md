- 领域变更通过带 `kind: 'goal/change'` 与 `version` 字段的 `GoalChangeMeta` 持久化，回放端用 `decodeGoalChange` 严格校验后再应用。
- 所有对外 API 参数在进入领域边界前由独立的 `resolve*` 函数（如 `resolveObjective`、`resolveMaxGoalRounds`、`resolveBlockReason`）进行校验并抛出 `GoalError`。
- 阶段转换统一通过私有 `transition`/`commitCurrent`/`commitSnapshot` 方法封装，禁止直接修改 `phase`/`revision` 等字段。
- 比较-设置（CAS）通过 `GoalRef { id, revision }` 传递，所有写操作先 `expectCurrent` 校验 ref 与当前缓存一致。
- 进程内激活状态 `activation`（armed/disarmed）与持久化 `phase` 分离，仅在 `GoalCache` 中维护并通过 `pendingActivation` 在 append 后按 seq 对齐。
- 宿主侧类型通过 `declare module` 扩展第三方库的映射接口（`SessionProjectionMap`、`SessionEventMap`、`MessageSourceMap`、`CordisEvents`），避免污染全局命名空间。
