模块以四个独立 npm 包分层组织，依赖方向单向收敛于核心领域包 `@deepseek-ai/dsh-goal`：
- `goal/` 是领域内核，`src/index.ts` 中的 `GoalService` 继承 `TypertRemoteService`，通过 `ctx.goals` 注入到 Cordis Context；使用 `session.events` 上的 `goal/change` 事件做严格回放折叠（`fold.ts`），并维护进程内 `WeakMap<Session, GoalCache>` 缓存当前快照、`roundsStarted`、`activation`（armed/disarmed）和 `pendingActivation` 以跨同步 append 边界协调自动续轮。
- 纯类型与宿主词汇分离：`types.ts` 仅含客户端安全的 `GoalSnapshot`/`GoalView`/`GoalProjection` 等，并通过 `declare module` 扩展 `dsh-session-projection` 的 `SessionProjectionMap` 注册 `goal` 投影键；`domain.ts` 声明 `GoalChangeMeta`、`GoalMessageSource`、`SessionEventMap['goal/change']`、`CordisEvents['goal/changed']` 等宿主侧契约。
- `fold.ts` 提供不可变回放折叠器 `applyGoalEvent`/`foldGoal`，对每个 `goal/change` 进行版本校验、字段白名单、阶段转换合法性检查（edit/pause/resume/complete/block/clear），并在 `user/message` 中校验 `goal` 来源的 round 递增与预算上限。
- `runtime.ts` 集中协议常量 `GOAL_CHANGE_VERSION` 与 `GoalError`（基于 `HarnessError` 的稳定错误码）。
- `tool-goal/` 暴露 `get_goal`/`create_goal`/`update_goal` 三个 LLM 工具，通过 `authority.ts` 区分 direct human 与 goal-round 执行上下文，并对 `blocked` 动作施加 `blockedAfterConsecutiveRounds` 阈值策略。
- `command-goal/` 提供 `/goal` 人类斜杠命令，解析 create/edit/pause/resume/clear/show 并调用 `ctx.goals`。
- `goal-round-driver/` 在 agent 空闲时自动排队下一轮 goal 消息，通过 `agent/inbox` 监听与 `PreStepDecision` 钩子实现竞态围栏，达到 `maxGoalRounds` 或入队失败时将 goal 置为 `blocked`，并在 session 结束/错误时 `disarm` 自动续轮权限。
- 所有包均遵循 `package.json` 的 `exports` 多入口约定（`.`, `./invariant`, `./src/*`），并通过 `peerDependencies` 声明对 `dsh-agent`/`dsh-session`/`dsh-tools`/`cordis` 等的弱耦合。
