本模块由 goal、plan、workflow、subagent、schedule 五个并列的 package 组成，它们不直接互相 import，而是通过 Harness Loader 注入的 `ctx` 能力接缝协作：goal 通过 `ctx.tools` 注册 command-goal/tool-goal，plan 通过 `ctx.commands` 提供 /plan 命令并监听 plan:policy 提示段，workflow 通过 `ctx.tools` 暴露 workflow/ralph 工具并在 worker 线程中调度 subagent，subagent 通过 `ctx.subagents` 能力被其他包调用以实现进程隔离执行，schedule 通过 `ctx.tools` 暴露 after/at/every 定时工具并以事件日志为持久化源。所有子包遵循相同的契约：每个 package 在 `src/invariant.ts` 注册自身不变量，测试位于 `tests/` 目录，README 使用统一 i18n 格式描述模型可见行为；上层编排器（如 boot/host/session）在启动时按依赖顺序加载这些 service/plugin，使 goal 的续轮驱动、plan 的退出审核、workflow 的工作流步骤、subagent 的子进程委派以及 schedule 的定时触发在同一 Agent 会话的事件流中共存。
