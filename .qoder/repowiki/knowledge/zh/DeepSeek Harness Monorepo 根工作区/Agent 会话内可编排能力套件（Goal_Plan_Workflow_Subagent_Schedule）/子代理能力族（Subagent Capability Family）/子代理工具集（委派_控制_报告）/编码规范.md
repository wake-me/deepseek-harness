- 插件统一以 `export const name` + `export const inject = [...]` + `export function apply(ctx, config?)` 的形式暴露，供 Cordis 加载器发现与装配。
- 配置对象配合 Schemastery 的 `z.object({...}).default(...)` 定义，并在 `apply` 入口处对直调场景进行二次校验（如 `maxDepth`、空 `toolFilter`）。
- 工具输出采用 discriminated union（含 `kind` 字段区分 foreground/background/continuable），并通过 `output.render` 将结构化结果转换为纯文本提示。
- 通过 `ctx.systemPrompt.section({ order, text })` 注入带优先级的系统提示片段，并按 provider 是否已就绪返回空字符串以实现条件可见性。
- 资源释放采用成对的 dispose 函数模式：`ctx.tools.register` 返回 disposer，结合 `ctx.on('...-removed')` 或 try/catch 聚合错误后统一调用，失败时使用 `AggregateError` 汇总。
- 所有异步执行路径均透传 `exec.signal` 作为 AbortSignal，并在取消时返回 `{ status: 'killed' }` 等标准化 JobOutcome。
