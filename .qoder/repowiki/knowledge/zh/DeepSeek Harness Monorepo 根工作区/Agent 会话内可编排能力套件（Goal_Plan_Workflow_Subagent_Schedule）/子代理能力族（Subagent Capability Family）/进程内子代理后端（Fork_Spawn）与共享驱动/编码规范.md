- 每个 Provider 包都导出 `name`、`inject = ['subagents']`、`Config` 类型及对应 `schemastery` 校验对象，并以 `apply(ctx, config)` 函数注册到 `ctx.subagents.registerProvider`。
- Provider 类实现 `SubagentProvider` 接口，显式声明 `capabilities` 能力集与 `inheritsParentContext` 布尔标志，区分 fork 与 spawn 的上下文继承语义。
- 子代理生命周期通过 `startInProcessRun(request, options)` 统一封装，上层 Provider 只负责准备 seed/prompt/策略参数，不直接操作 AgentHandle。
- 结构化输出通过动态注册同名工具 `structured_output` 与第 190 序的 systemPrompt section 实现，并使用 WeakMap 按 ToolExecution 暂存值，最终经 `tools/result` 事件提交。
- 会话事件切片采用“边界索引”方式：fork 模式记录 `activationBoundary`，spawn 模式为 0，结果读取时统一对 `child.session.events.slice(boundary)` 调用 `foldConsumedWork` 与 `finalAssistantOutput`。
- 取消通过 `AbortSignal` 监听并在 finally 中移除 listener，同时将 `cancelled` 标志传入 `readResult` 以将非 completed 的 stopReason 提升为 `aborted`。
