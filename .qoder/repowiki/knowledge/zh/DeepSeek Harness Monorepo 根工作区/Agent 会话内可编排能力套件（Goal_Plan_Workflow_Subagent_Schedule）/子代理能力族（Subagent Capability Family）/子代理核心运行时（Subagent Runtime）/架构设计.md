模块以 `src/index.ts` 中的 `SubagentRuntime`（继承自 Cordis `Service`）为唯一对外入口，通过 `registerProvider` 维护一个按名称索引的 `Map<string, SubagentProvider>`，并在构造时注入 `ctx.agents` 与 `ctx.sessionProjections`。

内部按职责拆分为多个文件：
- `types.ts` 定义跨包契约（`SubagentProvider`、`SubagentStartRequest`、`SubagentRun`、`ContinuableCreateSpec` 等），是 Provider 与消费者之间的稳定边界；
- `descriptor.ts` 维护版本化的 `subagent/descriptor` 持久化事件格式（`SUBAGENT_DESCRIPTOR_VERSION`），提供 `snapshotSubagentDescriptor` / `foldSubagentDescriptor` 做写入前校验与冷恢复解析；
- `continuation.ts` 实现 `SubagentContinuationManager`，负责可延续子 Agent 的 ID 预留、描述符持久化、Activation 驻留生命周期、冷恢复、父侧结算通知与 `drainDescendants`；
- `child-agent.ts`、`depth.ts`、`lifecycle.ts`、`activation-setup-registry.ts`、`list-children.ts`、`projection.ts`、`out-of-process.ts`、`assistant-output.ts`、`run-settlement.ts`、`error.ts`、`invariant.ts` 等作为纯函数或小型服务被 `SubagentRuntime` 组合调用；
- `client.ts`、`descriptor-seed.ts`、`projection-types.ts` 暴露面向上层工具的类型与辅助。

依赖方向单向：`index.ts` → 各子模块；子模块之间仅通过类型与少量函数引用耦合，不反向依赖 `SubagentRuntime`。Provider 实现位于独立包（`dsh-subagent-spawn-in-process`、`-fork`、`-acp`），本模块只持有接口与调度逻辑。可选依赖（session persistence、session projection、jobs、user-approval、sandbox）通过 `peerDependenciesMeta.optional` 声明，运行时按需消费。
