- 对外契约集中在 `types.ts`，其他文件仅 import type 并避免把内部控制接口泄漏到该文件，使 `types.ts` 成为稳定的发布表面。
- Provider 能力通过 `provider.capabilities` 布尔位 + `assertCapabilities` 在 `start()` 入口处 fail-loud 校验，未满足的能力立即抛出 `SubagentError`，禁止静默降级。
- 所有副作用（注册 Provider、注册 Continuable Setup、注入 continuation manager）都通过 `ctx.effect` 包裹，返回精确的可复用 disposer，保证 HMR 与作用域内回滚。
- 错误统一通过 `SubagentError` 携带语义化 code（如 `NO_PROVIDER`、`UNSUPPORTED_CAPABILITY`、`CONTINUATION_UNAVAILABLE`、`CANCELLED`），而非裸 throw。
- 可延续子 Agent 的生命周期通过 `SubagentContinuationManager` 集中管理，Provider 仅参与 `prepareContinuable` 返回数据，不持有 `AgentHandle`、turn 或 teardown 权限。
- 持久化描述符采用显式白名单字段 + `SUBAGENT_DESCRIPTOR_VERSION` 版本号，新增字段必须升级版本，禁止对 `AgentOptions` 这类合并扩展对象直接序列化。
