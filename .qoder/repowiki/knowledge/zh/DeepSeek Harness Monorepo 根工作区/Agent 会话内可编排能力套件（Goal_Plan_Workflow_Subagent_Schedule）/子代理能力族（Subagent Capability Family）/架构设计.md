以 subagent/ 为核心运行时，定义 SubagentProvider 接口、命名注册表、会话枚举与投影；各子包通过独立 npm 包对外暴露统一的启动入口并自行向 ctx.subagents 注册：
- provider_adapters（subagent-acp / claude-code / codex / dsh-sdk）实现外部子代理的进程外运行适配；
- in_process_drivers（subagent-in-process-driver + fork/spawn variants）提供基于 Cordis Agent 的进程内运行后端；
- tool_wrappers（tool-subagent / control / report）作为 Cordis 插件把委托、控制与回传通道挂载到 ctx.tools 或子作用域。
所有子包共享 core_engine 的类型契约（types.ts、descriptor.ts、continuation.ts、projection-types.ts），并通过 invariant.ts 在各自包内做运行时断言；跨包协作仅通过 ctx.subagents 与 ctx.tools 两个上下文键完成，无直接 import 依赖。
