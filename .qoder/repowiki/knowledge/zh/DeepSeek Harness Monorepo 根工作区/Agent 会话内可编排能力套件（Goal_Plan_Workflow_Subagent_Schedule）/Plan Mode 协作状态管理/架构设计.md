模块以 `@deepseek-ai/dsh-plan-mode` 包为核心，基于 Cordis `Service` 实现 `PlanModeController`（`src/index.ts`），通过注入 `tools`、`systemPrompt`、可选的 `commands` 与 `sessionProjections` 子上下文来组合能力：
- 会话事件层：扩展 `SessionEventMap` 定义 `plan/mode { active: boolean }` 日志事件，并通过 `foldPlanMode` 对事件流做 last-wins 折叠得到当前模式。
- 状态持久化：使用 session-projection RFC 注册 `plan` 投影键，将 `/plan` 命令选择与 `plan/mode` 事件纯函数式归并为 `{active, pending}` 视图，支持冷启动重放恢复。
- 提示集成：通过 `ctx.systemPrompt.section('plan:policy')` 在 plan mode 激活时注入部署方提供的 guidance 文本。
- 工具与命令：注册稳定的 `exit_plan_mode` 工具（始终存在，不随模式切换）和可选的 `/plan` 命令；工具调用经 `userQuestions` 通道发起“Approve / Keep planning”审核，审核结果在下一个 accepted in-turn pre-step 边界写入日志。
- 不变量校验：`src/invariant.ts` 作为独立 companion plugin，在事件进入持久化前校验 `plan/mode` payload 形状。
依赖方向单向向外：仅依赖 `@deepseek-ai/cordis`、`dsh-session`、`dsh-tools`、`dsh-system-prompt`、`dsh-user-questions`、`dsh-invariants`、`dsh-session-projection` 等 peer 包，自身不持有运行时状态，所有状态均来自 session 日志或 WeakMap 挂起的 per-agent 意图。
