- 对外暴露的纯类型集中在 `src/types.ts`，并通过 `export type * from './types.ts'` 从根与 `./client` 双入口 re-export，避免类型重复。
- 可选能力（如 commands、sessionProjections）通过 `ctx.inject([...], handler)` 延迟注册，确保无该子上下文时插件仍可正常加载。
- 会话状态变更统一通过 `session.append('plan/mode', ...)` 写入日志，并由 `foldPlanMode` 以 last-wins 方式折叠，而非维护内存中的单例状态。
- 跨 turn 的状态变更采用 pending-intent + step-boundary flush 模式：在 open turn 内暂存于 `WeakMap<Session, intent>`，在下一个 accepted in-turn pre-step 的 `onBoundary` 中追加日志。
- 配置解析集中到 `resolveConfig` 并在构造期抛出错误，未知字段也会报错，保证部署配置在插件加载阶段即被严格校验。
