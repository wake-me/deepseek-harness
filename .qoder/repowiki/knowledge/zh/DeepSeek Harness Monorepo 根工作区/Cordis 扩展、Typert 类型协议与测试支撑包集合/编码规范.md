- 每个子包在 `src/` 下提供 `invariant.ts` 并通过 `package.json` 的 `exports["./invariant"]` 单独导出，使业务入口与诊断逻辑解耦。
- 所有包统一采用 `lib/` 作为 tsdown 构建输出目录，并在 `files` 中显式声明发布产物（`lib/index.js`、`lib/types/**/*.d.ts`、`lib/invariant.js`）。
- 对外 API 通过 `index.ts` 集中 re-export，并将类型与实现分离（`export { ... } from './xxx.ts'` 同时 `export type { ... }`）。
- Cordis 插件通过 `inject` 数组声明所需服务，并通过 `apply(ctx)` 函数完成装配，同时将自身能力以 `ctx.provide('dynamicCordisRunner', face)` 等形式挂载到 Context。
- 错误处理统一包装为具名 Error 子类（如 `InvariantError`、`TypertEmitError`），并附带稳定 `code` 字段以便上层区分失败原因。
- 测试组织遵循 `tests/*.spec.ts` 命名约定，并使用 `__snapshots__/` 或 `.generated-model-*` 临时目录存放快照与生成产物。
