模块由两个相互依赖的 hatchling 包组成：`python/sdk`（`deepseek-harness-sdk`）暴露面向用户的 API，`python/sdk-runtime`（`deepseek-harness-runtime-bin`）打包可执行二进制及默认 cordis 配置。
- `api.py` 定义高层 `DeepSeekHarness`/`Session`/`RunResult`，负责将用户输入归一化、启动运行时、轮询 `session.status=idle` 并提取最终回复与 finish reason。
- `client.py` 实现底层 `HarnessClient`：通过 `subprocess.Popen` 拉起运行时进程，使用独立 reader/stderr 线程按行读取 JSON-RPC 消息，基于 `queue.Queue` + `threading.Lock` 维护请求-响应等待器、通知订阅者与入站请求队列；支持超时、优雅 shutdown、以及基于 `subagent.started` 事件构建的子代理父子关系以过滤 session 通知。
- `models.py` 用 pydantic/dataclass 声明跨进程协议类型（`Notification`、`IncomingRequest`、`InitializeResponse` 等）。
- `errors.py` 定义异常层次 `HarnessError` → `TransportClosedError`/`SdkProtocolError`/`JsonRpcError`。
- 依赖方向单向：`api` → `client` → `models/errors`；SDK 通过可选导入 `deepseek_harness_runtime.resolve_bundled_launch_args` 和 `bundled_default_config_path` 动态发现捆绑运行时与默认 cordis 配置，并通过 `uv` editable source 指向同级 `sdk-runtime` 目录以便开发时联调。
