- 公共配置类统一使用 `@dataclass(slots=True)` 定义（如 `HarnessConfig`、`DeepSeekHarnessConfig`、`RunResult`、`Notification`），以减少内存占用。
- 对外 API 采用上下文管理器模式（`__enter__`/`__exit__`）确保运行时进程被可靠启动与关闭，调用方应优先使用 `with DeepSeekHarness(...)` 或显式 `close()`。
- JSON-RPC 消息通过 `json.dumps(message, separators=(',', ':'))` 压缩后按行写入 stdin，读端逐行 `json.loads` 解析，保持流式低延迟。
- 跨进程数据契约集中在 `models.py`，使用 pydantic `BaseModel` 进行响应反序列化（如 `InitializeResponse`、`ServerInfo`），避免在业务层手写字段校验。
- 错误体系分层：传输层失败抛出 `TransportClosedError`，协议违规抛出 `SdkProtocolError`，JSON-RPC 错误包装为 `JsonRpcError(code, message, data)`，均继承自 `HarnessError`。
- 通知订阅通过 `subscribe_notifications` 返回带 `close()` 的 `NotificationSubscription` 对象，配合 `drain` 非阻塞消费，并在异常路径中统一清理订阅者映射。
