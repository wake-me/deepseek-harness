- 投影单元统一实现 `ProjectionDefinition` 接口，以纯同步的 init/apply/view 三函数描述状态机，并通过 `stateVersion` 标识序列化兼容性。
- 领域包通过 `declare module '@deepseek-ai/dsh-session-projection/types'` 对 `SessionProjectionMap` 进行声明合并来注册新的投影键，而非修改核心包。
- 所有持久化写入走 fail-soft 路径：`flushSoft`/`putSoft` 捕获异常仅记 warn 日志，保证缓存失败不会破坏主事件/读取路径。
- 写回采用双触发节流：累计 `writeEveryEvents` 条事件或到达 `writeIntervalMs` 间隔即落盘，并在 `turn/end` 与 `session/disposed` 两个强制边界无条件 flush。
- 应用状态变更通过返回同一引用（Object.is 相等）来短路变更通知，仅在 `apply` 产生新引用时才触发 change feed 与 schema 校验。
- 客户端与宿主共享类型：通过独立的 `types.ts` 与 `client.ts`（仅 re-export types）避免宿主值依赖泄漏到客户端聚合。
