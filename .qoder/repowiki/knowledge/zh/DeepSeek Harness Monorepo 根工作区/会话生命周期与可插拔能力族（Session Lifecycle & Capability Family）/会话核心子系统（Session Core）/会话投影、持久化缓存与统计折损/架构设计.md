本模块由三个相互协作的子包构成，围绕「纯函数投影 + 事件驱动 + 持久化折加速」这一核心契约展开：
- `session-projection`（核心）：定义 `ProjectionDefinition<K,S>`（init/apply/view/stateVersion）、`SessionProjectionRegistry`（Cordis Service，订阅 `session/event` 并 eager 推进每个注册单元的 state cell，使用 WeakMap 按 Session 缓存 per-unit watermark），暴露 `snapshot`/`checkpoint`/`restore`/`viewCheckpoint`/`restoreFloor` 等读写阶梯；类型表 `SessionProjectionMap` 通过声明合并开放给领域包扩展。
- `session-projection-cache`（持久层）：基于 `@deepseek-ai/dsh-storage-domain` 的 `session_projcache` 域，维护每 session 的检查点记录 `{identity, rows}`，以 count/interval 写回 + `turn/end`、`session/disposed` 两个强制落盘点实现 write-behind；提供 `cachedSnapshot`（零 I/O 列表）和 `coldSnapshot`（缓存行 → persistence readFrom tail → registry.restore 冷启动恢复）两条读取路径，并通过 identity（createdAt/cwd）防止跨生命周期污染。
- `session-stats`（领域投影）：作为 Cordis 插件（`name='session-stats'`，`inject=['sessionProjections']`）注册一个纯投影单元，将 step/start→assistant/message、tool/call→tool/result、assistant/chunk 等事件折叠为 turns/steps/llmMs/toolMs/ttftMs/decodeMs 等整日志指标，并通过 `declare module '@deepseek-ai/dsh-session-projection/types'` 将 `sessionStats` 键注入全局类型表。
依赖方向单向：session-stats → session-projection → dsh-session/dsh-storage-domain；session-projection-cache 同时依赖 session-projection 与 session-persistence 提供的 seam，三者通过 Cordis Context 注入解耦。
