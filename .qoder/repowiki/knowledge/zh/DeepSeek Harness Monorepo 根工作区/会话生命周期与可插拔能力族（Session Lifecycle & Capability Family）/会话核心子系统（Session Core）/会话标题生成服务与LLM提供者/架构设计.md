模块由四个相互协作的子包构成：
- `session-title`（核心）：导出 `SessionTitleService`（继承自 `@deepseek-ai/cordis` 的 `Service`），监听 `session/event`（`user/message`、`request/header`）、全局 `llm/stream` 和 `session/disposed` 事件，维护每个 session 的工作状态（revision/pending/active/fallback），实现 last-wins 折叠、确定性回退（`fallbackSessionTitle`）、用户重命名（`rename`）与显式刷新（`refresh`）。通过 `ctx.sessionProjections.register('title', ...)` 将最新标题以投影形式暴露给客户端。
- `session-title-llm`（共享库）：定义 `SessionTitleLlmConfig`、`resolveSessionTitleLlmConfig`、`registerSessionTitleLlmProvider`、`generateSessionTitleWithLlm`，封装统一的系统提示、JSON 消息框定、`BlockAssembler` 流式拼装、超时（`@deepseek-ai/dsh-timeout`）、finish reason 转换，并追加 `session/title-llm-request` 日志事件。
- `session-title-first-prompt-llm` 与 `session-title-all-prompts-llm`（具体插件）：仅通过 `apply(ctx, config)` 调用共享库的 `registerSessionTitleLlmProvider`，分别以 `'first-prompt'` / `'all-prompts'` 模式注册，差异仅在 `selectMessages` 选择器上。
依赖方向单向：两个 LLM 插件 → `session-title-llm` → `session-title`；核心不反向依赖任何 LLM 实现，从而保持纯日志 + 可插拔架构。配置校验统一使用 `schemastery` + `zod`，类型扩展通过 `declare module` 注入到 `@deepseek-ai/dsh-session/types` 的 `SessionEventMap` 与 `@deepseek-ai/dsh-session-projection/types` 的 `SessionProjectionMap`。
