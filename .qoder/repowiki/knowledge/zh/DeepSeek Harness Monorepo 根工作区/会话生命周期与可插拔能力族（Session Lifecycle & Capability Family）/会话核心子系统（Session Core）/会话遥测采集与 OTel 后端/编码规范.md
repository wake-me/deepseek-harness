- 通过扩展 `@deepseek-ai/cordis` 的 `Context` 与 `Events` 类型声明自定义服务键 `sessionTelemetry` 与水线事件 `session-telemetry/record`，使插件能力以类型安全的方式挂载。
- 所有捕获路径（live 事件、on-demand 回放、session/disposed 标记）均包裹在 `contain()` try-catch 中，确保后端或脱敏规则异常 fail-closed 且不阻塞 agent 循环。
- 对 session 事件进行固定投影后再交付：assistant/chunk 仅保留每 (turn,step) 的首条，其余通过 per-session `chunkSeen` 集合去重，避免重复上报。
- 记录统一采用 `{channel, time, severity, attributes, body}` 形状，其中 `attributes` 仅承载最小身份字段（session.id、event.type、event.seq 及可选 header 派生字段），body 保持不可变深拷贝。
- 后端实现通过继承 `SessionTelemetryBackend` 并实现 `sharing`、`emit`、`shutdown` 暴露策略与生命周期，将共享策略（full / feedback-only / disabled）与具体上报 SDK 解耦。
- 配置对象使用 `schemastery` 的 `z.object(...)` 声明并在构造函数内做运行时值校验（URL 协议、batch size、shutdown timeout），未知枚举值通过 `assertNever` 失败。
