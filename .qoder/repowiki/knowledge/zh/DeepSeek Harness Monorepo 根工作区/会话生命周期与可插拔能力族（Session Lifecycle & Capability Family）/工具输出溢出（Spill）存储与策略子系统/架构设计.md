本模块由三个相互独立的 npm 包组成，通过 Cordis 服务/插件机制协作：
- `spill`（`@deepseek-ai/dsh-spill`）：定义抽象服务 `SpillStore extends Service` 及类型 `SaveTextSpill` / `SpillRef` / `SpillLocator`（基于 `@deepseek-ai/dsh-brand` 的 Branded 字符串），并通过 `declare module '@deepseek-ai/cordis'` 扩展 `Context.spillStore`，作为存储后端契约。
- `spill-local`（`@deepseek-ai/dsh-spill-local`）：实现 `LocalSpillStore`，依赖 `spill`；通过 `store.ts` 暴露无 `ctx` 的纯函数 `privateRoot()` / `sessionDir()` / `encodeSegment()` / `saveTextFile()`，以 `<root>/session-<sha256(sessionId)>/<随机前缀>-<安全名称>` 布局写入 0600 权限文件，路径段经 `encodeSegment` 防目录穿越。
- `spill-policy`（`@deepseek-ai/dsh-spill-policy`）：Cordis 插件，注入 `tools`，监听 `tools/post-execute` 与 `tools/code-dispatch-log` 两个钩子，调用 `ctx.spillStore.saveText` 保存全文并返回 `TextRetainer` 生成的 head/tail 预览 + 提示；对 `read` 工具、嵌套复合调用、值替换场景做跳过处理，保证最佳努力且不破坏原调用成功语义。
依赖方向单向：`spill-policy` → `spill`（仅类型），`spill-local` → `spill`（运行时服务），三者之间无循环依赖。
