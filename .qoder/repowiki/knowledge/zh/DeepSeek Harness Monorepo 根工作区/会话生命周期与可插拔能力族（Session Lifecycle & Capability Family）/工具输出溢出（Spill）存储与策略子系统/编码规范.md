- 存储后端通过继承 `SpillStore extends Service` 并在构造函数中以 `'spillStore'` 为服务名注册，实现方只暴露 `saveText` 一个方法。
- 对外部不可信输入（sessionId、suggestedName）一律通过 `encodeSegment` 编码为单一路径段后再拼接，禁止直接使用原始字符串构造文件系统路径。
- 文件写入采用 `open(path, 'wx', 0o600)` 独占写 + 所有者只读权限，防止已存在的符号链接重定向写入。
- 策略插件通过 `ctx.on('tools/post-execute', ..., { prepend: true })` 和 `ctx.on('tools/code-dispatch-log', ..., { prepend: true })` 在流水线最前端拦截，先 `await next()` 再对结果做有界替换。
- 所有可配置项使用 `@deepseek-ai/schemastery` 的 `z.object({...})` 声明并在加载时校验，错误在部署阶段抛出而非运行时静默降级。
- 跨包共享的类型（如 `SessionId`、`CallId`）通过类型导入而非运行时依赖引入，保持策略层对工具/代理实现的解耦。
