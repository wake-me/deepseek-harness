- 每个子包均暴露一个继承自 `Service` 的主类，并通过 `static inject` 声明依赖、`static Config` 用 schemastery 校验配置、`readonly config` 保存解析后的配置对象。
- 对外扩展 `@deepseek-ai/cordis` Context 接口时使用 `declare module '@deepseek-ai/cordis' { interface Context { ... } }` 合并键（如 `compaction`、`toolResultPruner`）。
- 会话事件通过 `declare module '@deepseek-ai/dsh-session/types' { interface SessionEventMap { ... } }` 扩展，新增的 `compaction/*` 事件集中定义在 `types.ts`。
- 错误分类采用带字面量 `code` 的专用 Error 子类（如 `ManualCompactionError`），由上层命令层根据 code 分支映射为用户可读文本。
- 可选项服务通过 `this.ctx.get('key')` 获取并判空后再调用（如 `toolResultPruner`），使基本压缩包在不安装裁剪器时仍可独立工作。
- 配置与常量通过独立的 `config.ts` + `types.ts` 文件组织，并以 `resolveConfig` 函数返回只读结构，避免在业务逻辑中散落原始配置。
