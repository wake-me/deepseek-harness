- 所有对外暴露的服务均继承 Cordis `Service` 并通过 `static inject = ['sessions']` 声明依赖，同时用 `declare module '@deepseek-ai/cordis'` 扩展 `Context` 类型以挂载 `sessionQuery` 字段。
- 配置对象统一使用 `@deepseek-ai/schemastery` 的 `z.object({...}).default(...)` 进行校验与缺省值推导，并在构造函数中解析为不可变 `ResolvedConfig` 只读属性。
- 错误统一通过 `SessionQueryError` 抛出，并附带语义化的 `SESSION_QUERY_*` 错误码（如 `SESSION_QUERY_INVALID_CONFIG`、`SESSION_QUERY_SEARCH_DISABLED`、`SESSION_QUERY_STALE_CURSOR`）。
- 分页游标采用 base64url 编码的 JSON 结构体（含 `version`、`instance`、`scope`、`fingerprint`、`generation`、`offset`），在解码时校验实例归属、作用域、指纹与 generation 一致性。
- SQL 构建遵循“谓词片段 + 绑定数组”模式：`buildSessionWhere`/`buildEventWhere` 返回 `{ sql, params, predicateCount }`，再由调用方拼接并调用 `assertPortableBindingCount`/`assertFts5OuterPredicateCount` 限制参数规模。
- 对 live 与 persisted 源的变更通过 `_observeStable` 重试最多两次来容忍短暂抖动，并以 `global_generation`/`local_generation` 双代际计数器驱动 cursor 失效与增量重索引。
