- 对外配置采用 discriminated union（`transport: 'stdio' | 'streamable-http'`）配合 Schemastery/Zod 联合 schema 进行运行时校验与默认值填充。
- 所有跨进程/跨连接状态变更通过 `ctx.effect` 注册副作用，并在回调中返回清理函数以实现 HMR 友好的资源释放。
- 工具公开名由纯函数 `publicToolName(serverName, rawName)` 生成，遵循 DeepSeek 函数名约束（64 字符、`[A-Za-z0-9_-]`），必要时附加 12 位 SHA-256 哈希保证唯一性。
- 连接与工具同步采用「代」(generation) 模式：每次重连/重同步创建新 `Client`，通过 `isCurrent` 守卫与 `syncChain` 串行化确保 swap 原子性，避免并发竞态。
- 重连策略集中通过 `resolveReconnectPolicy` 归一化并冻结，对 `initialDelayMs`、`maxDelayMs`、`maxAttempts` 做边界校验后统一被 supervisor 消费。
- 对外部 MCP 服务器的输入输出均视为不可信网络边界，使用 Zod schema 二次校验（如 `RawCallToolResultSchema`、`ListToolsResultSchema`）后再进入业务逻辑。
