模块以 `src/index.ts` 作为 Cordis 命名空间插件入口（导出 `name='mcp-client'`、`inject=['tools']` 和 `apply(ctx, config)`），通过 discriminated union 的 `Config`（`stdio` / `streamable-http`）选择传输层。
- `transport.ts`：根据 `config.transport` 工厂式创建 `StdioClientTransport`（使用 `dsh-subprocess` 的 `scrubbedParentEnv` 清理子进程环境变量）或 `StreamableHTTPClientTransport`。
- `connection.ts`：实现连接监督器 `startConnection`，维护单例 `Client` 生命周期、`notifications/tools/list_changed` 重同步、指数退避自动重连（`resolveReconnectPolicy` 校验策略）、失败预算（`maxAttempts`）与优雅关闭；暴露 `{ ready, dispose }` 句柄。
- `tools.ts`：工具桥接层，负责分页拉取 `tools/list`、用 `publicToolName(serverName, rawName)` 生成确定性公开名（64 字符 + SHA-256 后缀防碰撞）、两阶段 swap（先构建新代再替换旧代 disposers）、将 MCP 结果映射为 harness `ContentBlock` 并处理 `isError`。
- 依赖方向：`index → connection → {transport, tools}`，`tools` 仅依赖 SDK 与 `@deepseek-ai/dsh-tools`，不反向引用 connection。
- 测试位于 `tests/`，包含 fixture server、e2e、reconnect 等用例。
