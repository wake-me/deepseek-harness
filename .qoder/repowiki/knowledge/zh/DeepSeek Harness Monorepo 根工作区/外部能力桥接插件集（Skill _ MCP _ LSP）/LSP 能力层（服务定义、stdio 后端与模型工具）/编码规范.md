- 每个子包以命名导出 `apply(ctx, config)` 作为 Cordis 插件入口，并通过 `inject` 数组声明所需上下文服务。
- 配置对象使用 `schemastery` 的 `z.object({...}).default(...)` 模式定义 schema，并在 `apply` 中用 `assertPositiveInteger` / `assertTimer` 等辅助函数做运行时校验。
- 跨包错误统一通过 `LspError` 抛出并附带稳定 `code`（如 `LSP_INVALID_PROVIDER`、`LSP_CONFLICT`、`LSP_UNAVAILABLE`、`LSP_DISPOSED`），调用方按 code 分支而非解析 message。
- 资源生命周期通过 `ctx.effect` 注册 disposer，确保 provider 注销、实例销毁与队列清理成对出现，并在 dispose 后拒绝新请求。
- 对外暴露的类型集中在 `types.ts`，并通过 `export type { ... }` 从 `index.ts` 重新导出，保持 API 面最小化。
