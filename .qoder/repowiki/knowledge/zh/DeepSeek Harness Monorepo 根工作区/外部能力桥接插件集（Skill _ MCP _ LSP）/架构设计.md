三个子包各自独立实现一个 Cordis 插件：`packages/skill/*` 通过 provider 注册中心发现并合并本地/用户/项目目录中的技能；`packages/mcp/mcp-client` 启动外部 MCP 进程并通过 stdio/Streamable HTTP 协议将其工具发现后注入 `ctx.tools`；`packages/lsp/*` 用 `lsp` 定义服务契约、`lsp-stdio` 作为多进程后端管理 LSP 实例，再由 `tool-lsp` 把四种代码导航操作包装成模型工具。三者共同约定：对外均以 `index.ts` 导出插件入口，内部使用 `invariant.ts` 做运行时断言，测试位于同级 `tests/` 目录，并通过各自的 `package.json` 声明依赖与构建配置，使上层宿主可在同一生命周期内按需加载任意组合的外部能力。
