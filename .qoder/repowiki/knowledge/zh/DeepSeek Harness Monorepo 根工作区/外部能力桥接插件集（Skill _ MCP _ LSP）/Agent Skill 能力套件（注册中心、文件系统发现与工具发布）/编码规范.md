- Provider 通过导出 `name`、`inject`、`apply(ctx)` 三件套作为 Cordis 插件，在 `apply` 内调用 `ctx.skills.registerProvider()` 或 `ctx.tools.register()` 完成自注册。
- 所有 skill 名称统一遵循 kebab-case 正则 `/^[a-z0-9]+(?:-[a-z0-9]+)*$/`，并通过 `isSkillName` 在候选与定义两端进行校验。
- 通过 `rank`（如 `PROJECT_DSH_RANK=100`、`USER_AGENTS_RANK=500`、`BUNDLED_SKILL_RANK=600`、`RUNTIME_RANK=250`）表达来源优先级，配合 providerOrder 与 localOrder 实现稳定的同名覆盖顺序。
- 对外暴露的配置对象使用 Schemastery `z.object({...}).default(...)` 声明并附带默认值，构造函数中对数值字段执行正整数断言。
- 异步操作统一通过 `AbortSignal` 传播取消：`waitWithAbort`、`throwIfAborted`、`signal?.throwIfAborted()` 在 I/O 前后检查，provider 的 `list/get` 必须响应 abort。
- 模型可见文本统一通过 `renderSkillContent` / `renderCatalogMessage` / `escapeText` 输出，禁止直接拼接 XML 标签，确保 `<skill_content>`、`<available_skills>` 等框架不被外部输入破坏。
