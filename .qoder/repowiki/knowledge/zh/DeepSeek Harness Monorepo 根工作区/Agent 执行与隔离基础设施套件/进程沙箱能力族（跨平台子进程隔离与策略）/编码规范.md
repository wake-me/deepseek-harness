- 每个包通过 `declare module '@deepseek-ai/cordis'` 扩展 Context 接口，将服务挂载到固定键名（`ctx.sandbox`、`ctx.sandboxPolicy`），并以 `extends Service` 的形式实现。
- 配置对象采用 `static Config: z<Config>` 静态字段声明，配合 schemastery 提供默认值与运行时校验，构造函数中直接读取已归一化的配置。
- 失败关闭（fail-closed）：当无可用后端或环境不支持时抛出 `SandboxUnavailableError`（携带 `SANDBOX_UNAVAILABLE` 错误码），禁止静默降级为未受限制执行。
- 每个 runner 后端通过常量映射集中声明其 `DENIAL_SIGNATURES` 与 `RUNNER_FAILURE_RULES`，使调用方按后端方言匹配 stderr 而非假设跨后端一致。
- 资源清理采用 try/catch 收集多个 cleanup 失败的 `AggregateError` 模式（如 init/dispose 中的 SID 释放、DACL 撤销、句柄关闭），保证部分失败不会吞掉原始错误。
- 测试通过 `internals.*` 钩子注入 fake 平台、runner、probe 与文件系统操作，使得同一套测试可覆盖 Linux/macOS/Windows 各条链的分支。
