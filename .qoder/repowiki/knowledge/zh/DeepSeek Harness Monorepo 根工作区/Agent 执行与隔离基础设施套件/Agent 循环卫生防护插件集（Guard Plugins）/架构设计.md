本模块是 `guard/` 下的插件集合，每个子目录是一个独立可发布的 npm 包（`@deepseek-ai/dsh-repeat-tool-reminder`、`@deepseek-ai/dsh-tool-call-timeout-policy`），遵循统一的 Cordis 插件契约：导出 `name`、可选的 `inject` 依赖声明以及 `apply(ctx, config)` 入口函数，在加载时通过 `ctx.on('tools/post-execute' | 'tools/execute' | 'agent/pre-step')` 注册监听器。

- `repeat-tool-reminder`：基于 WeakMap<Agent, Chain> 维护每个 Agent 的连续重复调用链，对工具名按 `include`/`exclude` 通配符模式过滤，使用深度键排序后的 JSON 字符串作为参数等价键；命中阈值时通过 `createUserMessage` 生成带 `kind: 'plugin'` source 的提示消息，以 `additionalContexts` 形式附加到 `PostToolDecision`，既不否决也不改写下游决策。
- `timeout-policy`：在 `tools/execute` 阶段读取工具定义的 `timeoutMs`，用 `@deepseek-ai/dsh-timeout` 的 `deadline`/`timeoutOf` 为 `exec.signal` 临时替换派生信号，若自身定时器先触发则返回结构化 `TOOL_TIMEOUT` 错误结果，并在 finally 中恢复上游信号。

依赖方向单向指向 `@deepseek-ai/cordis`（事件总线）、`@deepseek-ai/dsh-tools`（工具执行模型）、`@deepseek-ai/dsh-agent`（Agent 类型）和 `@deepseek-ai/dsh-timeout`（超时原语），不反向依赖上层编排逻辑；配置校验统一通过 `@deepseek-ai/schemastery` 的 schema + 运行时 fail-loud 检查完成。
