- 插件以 `export const name` + `export function apply(ctx, config)` 暴露最小接口，并通过 `ctx.on(...)` 在加载期注册事件监听器。
- 配置对象同时导出同名 schemastery schema（如 `Config`），并在 `apply` 中进行 fail-loud 的额外校验（空数组、非整数、小于下限值等直接抛错）。
- 对外部副作用通过 peerDependencies 声明（`dsh-tools`、`dsh-agent`、`cordis` 等），并以 devDependencies 引入以便本地测试，保持包无运行时强依赖。
- 插件内部状态使用 `WeakMap<Agent, ...>` 存储，随 Agent 生命周期自动回收，避免跨 Agent 泄漏。
- 通过 `additionalContexts` 而非修改下游决策来注入提醒或元数据，保证后续监听器仍可 veto/改写决策。
- 工具名匹配统一采用 `*` 通配符转 anchored RegExp 的方式（`wildcardToRegExp`），支持 `include`/`exclude` 白名单与黑名单组合。
