- 每个能力包都先导出一个继承自 `Service` 的抽象类（`SubprocessRuntime`、`ShellExecutor`、`TerminalSessionService`），并通过 `declare module '@deepseek-ai/cordis'` 向 Context 注入键名（`subprocess`、`shell`、`terminals`、`shellEnv`）。
- 实现类以 `<Name>Local` 命名（如 `LocalSubprocessRuntime`、`LocalBashExecutor`、`PwshLocalExecutor`），并通过 `static inject = ['...']` 声明所需服务依赖。
- 配置通过 `static Config: z<Config>` 配合 `installSettingsSection` 注册，并提供 `assertServiceable*Config` 函数在构造期校验正数/有限值与 `MAX_TIMER_DELAY_MS` 上限。
- 环境变量采用分层合并策略：executor 的 `ENV_OVERRIDES`（如 `NO_COLOR`、`TERM=dumb`、`PAGER=cat`）优先于用户 `env`，再叠加 `dshEnv`，由 `subprocess` 层的 `scrubbedParentEnv` 过滤敏感键与 `DSH_*` 前缀。
- 输出收集统一使用 collect-mode reader，通过 `readFrom(offset)` 实现增量读取，并以 `{ text, lossy, spillPath }` 结构返回，溢出时落盘到临时文件。
- PTY 会话通过 `TerminalSessionService` 的 owner-scoped 注册与 `Agent` 绑定，销毁时通过 `effect` 钩子自动清理，并使用 `AggregateError` 聚合多个关闭失败。
