本模块按「安全边界 → 执行载体 → 用户交互」分层组织：
- guard 通过 Cordis 事件钩子（repeat-tool-reminder、timeout-policy）在 Agent 循环中注入重复调用提醒与超时预算，不侵入主链语义。
- sandbox 定义 per-session 进程级隔离抽象（sandbox-local 多后端选择器 + sandbox-windows-acl FFI + sandbox-policy 策略解析），向上暴露统一服务接口。
- subprocess/shell/terminal 作为执行载体层，以 `subprocess`/`shell`/`terminal` 抽象服务 + `*-local`/`*-sandbox` 实现对沙箱策略进行注入，统一管理 bash/pwsh 进程生命周期、PTY 会话与持久化。
- code-runtime 提供跨后端的代码执行 seam，以 Node worker-thread 实现 TypeScript 程序隔离运行，并通过协议桥接输出限额。
各层通过 Cordis Loader 注册 service class 默认导出，消费方经 `ctx.<service>` 或 `ctx.get(name)` 获取；每个包独立维护 `src/invariant.ts` 并在根 README.zh.md 中声明模型/Token/KV-cache 影响，形成统一的契约与可观测性边界。
