- 每个包以 service class 默认导出对外暴露能力，函数型插件则命名导出 name/inject/Config/apply，禁止混用两种形式。
- 可选服务通过 ctx.get(name) 读取，已声明注入的服务才使用 ctx.<name> 属性代理。
- 每个包在 src/invariant.ts 注册自身 manifest 名称并检查事件/数据关系，空安装器需提供 No runtime invariant 理由。
- README 与 JSDoc 随变更同步更新，并使用 Model Experience 格式声明模型、Token、KV-cache 影响。
- 面向模型的契约（工具 schema、提示词、结果、诊断）仅包含任务相关概念，稳定文本需快照或 e2e 覆盖。
- 产品可见插件必须附带非单元测试的 REAL-composition 测试，通过 Loader 启动 cordis.yml 并断言用户可见输出。
