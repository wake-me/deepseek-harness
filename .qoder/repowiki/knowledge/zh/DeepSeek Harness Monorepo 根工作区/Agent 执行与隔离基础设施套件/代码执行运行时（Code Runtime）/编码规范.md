- 所有跨后端共享的保留标识符（语言关键字、保留全局名、错误成员）集中在 `code-runtime` 包中以 `ReadonlySet` 常量形式导出，各后端消费同一份清单以保证命名可移植性。
- 从不可信对端（worker→host、binding 参数/返回值）接收的数据一律先经 schema 或显式 `switch` 解析再使用，拒绝未知字段与非法类型，避免在消息监听器中抛错导致宿主崩溃。
- 运行结果采用「错误即字段」模式：`CodeRunResult` 中 `error` 可选字段承载失败原因，`run()` 本身仅在 Service Definition 契约误用时抛出异常，不将程序级失败转为 Promise rejection。
- 对外部副作用（日志、完成值、诊断信息）统一通过 `OutputLedger` 累计字节数并在超过 `maxOutputBytes` 时产出 `output-limit` 失败，而非在各处分散截断。
- 每个 `run()` 创建独立的 Worker 实例，并通过 `this.live` Set 追踪以便在 `teardown()` 中批量终止并 await 退出，确保无进程泄漏。
- 配置通过 `z.object({...}).default(...)` 声明默认值并在构造函数中对正数、安全整数等语义约束做额外校验，未满足时抛出带前缀的错误消息。
