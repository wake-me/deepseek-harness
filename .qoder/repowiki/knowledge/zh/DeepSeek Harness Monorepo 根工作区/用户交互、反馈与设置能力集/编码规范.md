- 每个服务通过 `declare module '@deepseek-ai/cordis' { interface Context { ... } }` 扩展宿主 Context，并在构造函数中以 `super(ctx, 'serviceName')` 注册服务名。
- 对外暴露的会话事件通过 `declare module '@deepseek-ai/dsh-session/types' { interface SessionEventMap { ... } }` 声明，并以 `session.append(...)` 追加到当前 session 的日志中。
- 所有外部输入在进入服务边界时进行规范化与冻结：命令定义经 `normalizeDefinition` 校验后 `Object.freeze`，结果经 `normalizeResult` 校验，settings 写入经 `cloneJsonShaped` 与 schema 双重校验后再持久化。
- 可插拔能力通过 `ctx.inject(['feature'], (featureCtx) => { ... })` 惰性接入，当宿主未提供对应服务时整个功能分支静默跳过，保证无侵入组合。
- 变更通知统一通过 `ctx.events.dispatch('emit', ['event/name'])` 逐个 listener 调用并 try/catch 包裹，避免单个 listener 抛错阻塞后续监听者。
- 配置对象使用 `static Config: z<...>` 声明，默认值在 schema 内部给出，构造时直接读取 `this.config` 而不重复解析。
