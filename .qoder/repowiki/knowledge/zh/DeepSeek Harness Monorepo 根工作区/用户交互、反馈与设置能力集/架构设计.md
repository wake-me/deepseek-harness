本模块由四个并列的包组成，每个包以 Cordis `Service` 或插件形式暴露到宿主 Context：
- `packages/interaction`：以 `commands`（`CommandRuntime`）为核心，基于 `@deepseek-ai/dsh-scope` 的 `ScopedLayers` 实现全局与 agent 作用域的命令注册表；`permission-presets` 通过 `PermissionPresetService` 组合 `dsh-sandbox-policy` 与 `dsh-user-approval` 的开关，并可选注册 `/permission` 命令和 `permissions` session projection；`user-approval` 定义 `ApprovalService`，在 turn 边界内追加 `approval/asked`/`approval/decided` 审计事件并通过 `ctx.waterfall('approval/request')` 分发答案器链；`tool-ask-user` 与 `user-questions` 作为轻量工具封装。
- `packages/feedback`：`command-feedback` 仅追加 `feedback/record` 日志事件并依赖可选的 `sessionTelemetry` 输出分享说明；`message-feedback` 通过 `TypertRemoteService` 暴露 `list/put/delete`，使用 `storageDomain` + `sessionPersistence` 对已完成的 assistant message 做带版本号的 KV 持久化，并以 per-session 队列串行写操作。
- `packages/settings`：`settings` 包定义抽象基类 `SettingsProvider`，维护命名空间注册、三层合并（schema defaults → base → user）、序列化写队列、revision 冲突检测与 `settings/updated` 事件；`installSettingsSection` 为消费方提供 settings 存在/缺失时的透明回退；`settings-file` 是文件型 Provider 的具体实现。
- `packages/preset`：`agent-presets` 负责从 `roots` 目录扫描 `agent.cordis.yml`，通过 `mountPreset` 创建按 preset id 缓存的 standing scope，并用 `bindScopeParent` 将 agent 作用域挂到该 mount 上；`persona` 提供轻量 persona 注入。
依赖方向单向向外：各子包通过 `ctx.inject` / `ctx.on` / `ctx.events.dispatch` 与宿主及其他 dsh-* 包协作，不反向依赖上层应用。
