- 每个子包在 src/index.ts 顶部以 JSDoc @module 标注包名（如 @deepseek-ai/dsh-*），并在注释中声明该库“library, not a plugin”的定位，不持有全局状态或事件。
- 对外 API 通过显式 interface + 具名函数/类导出，参数校验集中在构造函数或入口处的私有 assert* 函数（如 assertBudget、assertTimerDelay），失败时抛出带字段名的 Error。
- 超时与取消统一通过 AbortSignal 传递，超时原因封装为自定义 TimeoutReason（或 EEXIST 等 errno 判断），由调用方通过 timeoutOf 等工具提取而非直接 catch。
- 原子写与锁通过文件系统语义（wx 独占创建、rename 原子替换、.lock 后缀文件）实现跨进程协调，错误处理一律清理临时资源后重新抛出。
- 文本/字节裁剪保持 UTF-8 安全：截断处回扫 continuation bytes 丢弃不完整码点，确保返回字符串不会引入 U+FFFD 替换符。
- 环境/路径解析提供 display 辅助函数（如 dshHomeDisplay），将绝对路径映射为用户友好的符号形式（~/.dsh 或 $DSH_HOME），避免向终端暴露机器路径。
