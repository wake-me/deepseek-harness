本模块是 packages/util 下的多个独立 npm 子包集合，每个子包（atomic-write、brand、home-paths、launch-environment、native-command、output-retention、timeout）均自包含 package.json、tsconfig.json、src/index.ts、src/invariant.ts 及可选 tests/ 与 README.i18n.yaml，彼此之间无相互依赖，仅通过 Node 内置 API（fs/promises、child_process、os、path、crypto）实现，保证消费方引入时不污染业务依赖图。

- brand：纯类型层，导出 Branded<B> 名义类型原语，供其他包对跨边界 ID 做编译期区分。
- home-paths：集中管理 DSH_HOME 解析优先级（配置 > $DSH_HOME > ~/.dsh），并提供 tilde 展开、canonicalizeWatchPath 等路径工具。
- timeout：以 AbortSignal 为核心的超时抽象，提供 deadline/idleWatchdog 生成带 TimeoutReason 的信号、clampTimeout 校验与 timeoutOf 原因提取。
- output-retention：无状态 retainers（ItemRetainer、TextRetainer）按 head/tail/headTail 策略裁剪逻辑项或字节流，并产出 RetainedItems/RetainedText 与 describeOmitted/formatRetentionNotice 标准化提示。
- atomic-write：基于 wx 独占创建 + rename 的原子替换 withFileLock 跨进程写入协调，配合随机后缀临时文件保证读者始终看到完整旧/新内容。
- native-command：封装 execFile 的无 shell 命令执行，统一 utf8 编码、AbortSignal 传播与 Windows 控制台隐藏。
- launch-environment：构建不可变的 LaunchEnvironmentSnapshot，按 process/project-env/user-env 信任层级合并环境变量，并通过 cordis Context 扩展注入。

所有子包遵循同一目录约定：src/index.ts 暴露对外 API，src/invariant.ts 存放内部断言；README.md/README.zh.md/README.i18n.yaml 提供多语言文档；tests/ 使用 .spec.ts 命名对应单元测试。
