本模块以 Cordis 微服务框架为横向基础设施，各子包各自作为独立 npm 包暴露服务：
- scope 提供带作用域标签的上下文与事件路由原语，是 session、agent-loop、system-prompt、tools 等上层包的共同依赖；
- session 基于事件溯源维护追加型日志与派生表面投影，被 agent-loop 消费以驱动 turn/step 循环；
- tools 定义工具注册中心与执行水线（pre/guard/around/post/result），供 agent-loop 在工具调用阶段调度；
- agent-loop 实现 ReactLoopAgent 驱动，组合 session、tools 与 runtime-context 完成请求编排、取消与恢复；
- agent、agent-default-model、agent-tool-presentation、system-prompt 作为可插拔能力包，按约定注入到 agent-loop 的生命周期中。
所有子包共享同一套 TypeScript + tsdown 构建配置与 invariant 校验模式，并通过 package.json 中的 peerDependency / dependency 关系形成从底层 scope → session/tools → agent-loop → agent 的能力装配链。
