模块以 `src/index.ts` 暴露核心 API：通过 `createScope(ctx, key)` 在 Cordis 插件 fiber 上创建携带 `kScope` 标记的 `Context`，并用 `WeakMap<ScopeKey, ScopeKey>` 维护作用域键的父子链（由 `bindScopeParent`/`scopeChainOf` 访问），实现“注册可见性向下继承、事件准入向上追溯”的双向作用域模型；`scopeTarget(base, key)` 包装 subject 并注入 `CordisContext.filter`，使未打标签监听器全局可见、已打标签监听器仅当自身 tag 等于或祖先于 dispatch key 时接收事件。`src/store.ts` 提供共享存储层：`NamedEntries`/`AnonymousEntries` 分别管理命名与匿名插入有序表，`ScopedLayers<L extends ScopeLayer>` 将全局层与精确作用域层组织起来，并通过 `ctx.effect` 把变更与撤销绑定到注册上下文的生命周期，空层自动回收。`src/invariant.ts` 作为可选 companion 插件，订阅 `internal/dispatch` 事件，借助 `scoped-events.generated.ts` 生成的解析映射校验每次 scope-filtered 事件必须使用 `scopeTarget` 包裹且 carrier key 与参数中的 subject 一致。依赖方向单向指向 `@deepseek-ai/cordis` 与 `@deepseek-ai/dsh-invariants`，包内文件之间 `store.ts` 反向依赖 `index.ts` 的 `scopeChainOf`/`scopeOf`，形成 index → store 的单向引用。
