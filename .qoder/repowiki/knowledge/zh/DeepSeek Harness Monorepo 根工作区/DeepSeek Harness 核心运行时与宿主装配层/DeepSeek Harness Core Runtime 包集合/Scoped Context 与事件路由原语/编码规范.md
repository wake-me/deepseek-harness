- 作用域标识统一使用 `object` 类型的 `ScopeKey` 并通过 `WeakMap` 关联父子关系与 carrier 信息，避免强引用泄漏。
- 作用域链遍历采用从 child 到 root 的 `for` 循环 + `scopeParents.get(cursor)` 游标模式，并在 `linkScopeParent` 中检测环以避免死循环。
- 注册表项的撤销语义统一返回“幂等 undo 函数”，调用方负责在 effect 中 yield 该函数，确保作用域销毁时能精确回滚单条注册。
- `ScopedLayers.effect` 将 action 的同步返回值作为 undo，并在 effect 清理阶段统一执行 undo、空层回收与可选 `onChange` 通知，保证变更原子性。
- 对外 API 通过 TypeScript branded type（如 `ScopedBrand` unique symbol）对 carrier 进行类型级遮蔽，使 subject 属性仅在事件参数中暴露而非直接可访问。
