- 所有持久化边界的数据在进入 Session 前都先经 `snapshotJsonValue` 做一次 lossless JSON 校验与拷贝，再对消息体调用 `deepFreeze` 或 `freezeRestoredObject` 实现运行时不可变。
- 事件类型通过 merge-extensible 的 `SessionEventMap` / `TurnEndReasonMap` 接口扩展，新增事件只需合并新成员而不修改已有 union。
- 对外暴露的持久化类型（如 `SessionHeader`、`JsonValue`）从根入口剥离到 `types.ts` 并由 `exports` 单独导出，避免客户端被宿主 `ctx.sessions` 污染。
- Cordis 事件通过 `declare module '@deepseek-ai/cordis' { interface Events { ... } }` 在模块内扩展现有接口，而非自定义事件总线。
- 每个事件在 append 时强制携带 `surfaceOp`（append 或 replace）与可选 `sourceEventSeqs`，由 `SurfaceManager.validateNext` 统一校验其位置合法性与覆盖完整性。
- 错误码采用具名字符串联合（如 `SessionForkErrorCode`）配合专用 Error 子类（`SessionForkError`）返回，便于调用方按 code 分支处理。
