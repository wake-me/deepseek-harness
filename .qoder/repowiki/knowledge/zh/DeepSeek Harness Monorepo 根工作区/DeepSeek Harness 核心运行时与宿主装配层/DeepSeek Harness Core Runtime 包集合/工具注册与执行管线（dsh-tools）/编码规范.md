- 对外 API 通过 `src/index.ts` 统一 re-export，各子模块仅导出自身职责，避免跨文件直接耦合。
- 所有可序列化数据在跨越边界时通过 `snapshotJsonValue` 进行 lossless JSON 快照并 `deepFreeze`，确保结果不可变且可持久化。
- 错误采用继承自 `HarnessError` 的具名类（如 `ToolNotFoundError`、`ToolOutputError`、`CodeRunFailedError`、`JsonSchemaError`），携带稳定 `code` 字符串以便上层策略路由。
- 语言/渲染器扩展通过 `Record<string, ...>` 表 + `satisfies` 联合类型（如 `SDK_RENDERERS`、`RUN_CODE_FLAVORS`、`CodeSdkLanguage`）实现，新增语言需在多处同步添加成员以由编译器保证一致性。
- 作用域相关状态使用 `ScopedLayers` + `ToolLayer` 组合，每个 scope 贡献 tools/restrictions/guards/mode，并在变更时通过 `ctx.emit('tools/change')` 广播。
- 执行管线以 Cordis 事件水线形式组织（pre-execute → guard → execute → post-execute → result），监听器签名统一为 `(exec, next) => Promise<Decision>` 或返回决策对象，保持可组合的拦截链。
