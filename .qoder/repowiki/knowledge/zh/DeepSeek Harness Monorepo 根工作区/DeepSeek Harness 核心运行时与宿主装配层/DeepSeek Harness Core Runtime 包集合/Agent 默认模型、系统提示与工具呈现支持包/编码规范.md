- 每个包以 `src/index.ts` 导出主 Service 类或 `apply` 插件函数，并以同名 `src/invariant.ts` 存放类型不变量。
- 配置对象通过 `static Config: z<...>` 静态属性配合 Schemastery 进行运行时校验，字段使用 `.required()` / `.default(...)` 显式表达约束。
- 通过 `declare module '@deepseek-ai/cordis' { interface Context { ... } }` 将服务实例挂载到全局 Context 上（如 `agentDefaultModel`、`systemPrompt`）。
- 注册型 API（section/context/tools/variable）返回精确的 disposer 函数，内部统一通过 `this.layers.effect(ctx, fn, { label })` 管理生命周期。
- 分层作用域数据通过 `ScopedLayers` + `NamedEntries`/`AnonymousEntries` 组织，scoped 注册 shadow global 同名项，变更时触发 `system-prompt/change` 事件。
- 对外暴露的常量（如 `PERSONA_SECTION`、`TOOL_ORDER_REST`、`AGENT_DEFAULT_MODEL_SETTINGS_NAMESPACE`）集中定义以便跨包协作与覆盖。
