本模块由三个独立的 Cordis Service 包组成，均遵循 `src/index.ts` + `src/invariant.ts` + `package.json` + `tsconfig.json` 的扁平结构：
- `agent-default-model`：通过 `installSettingsSection` 将 `AgentDefaultModelConfig` 以 `settingsNamespace('agent-default-model')` 挂载到 settings 文档，暴露 `currentSelection()` / `saveSelection()` 读写 provider/model/reasoningEffort，并在无 settings provider 时回退到组合配置。
- `system-prompt`：核心是 `SystemPrompt` Service，基于 `@deepseek-ai/dsh-scope` 的 `ScopedLayers` 维护 global + scoped 多层注册表，提供 `section/context/tools/variable/suppressRuntimeContext` 注册 API；`assemble()` 合并各层、按 order 排序、执行 `system-prompt/assemble` waterfall，并通过 `renderPrompt` / `renderContextSnapshot` 完成 `{{var}}` 严格插值与工具排序（含 `<unlisted-tools>` 占位符校验）。
- `agent-tool-presentation`：最小插件，通过 `apply(ctx, config)` 在 composition scope 调用 `ctx.tools.presentAs(mode)` 声明 native/code/both 呈现模式，code 模式通过 `ctx.inject(['codeRuntime'], ...)` 等待运行时可用。
依赖方向单向：三者都依赖 `@deepseek-ai/cordis`（Service/Context/waterfall）、`@deepseek-ai/schemastery`（配置校验），并分别消费 `dsh-settings`、`dsh-scope`、`dsh-tools`、`dsh-llm` 等宿主能力，不互相引用。
