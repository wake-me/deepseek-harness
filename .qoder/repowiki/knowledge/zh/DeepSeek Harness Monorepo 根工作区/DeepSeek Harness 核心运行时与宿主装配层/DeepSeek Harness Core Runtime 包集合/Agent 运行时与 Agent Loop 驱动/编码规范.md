- 通过 `declare module` 扩展第三方类型（`@deepseek-ai/cordis` Context/Events、`@deepseek-ai/dsh-system-prompt` AssembleContext、`@deepseek-ai/dsh-typert-protocol` TypertLookupMap），把 agent 能力以类型安全方式接入宿主框架。
- 所有对外生命周期事件（`agent/created`、`agent/disposed`、`agent/status`、`agent/inbox/*`、`agent/session-start`、`agent/error` 等）统一通过 `Scoped<Agent>` 接收器进行 scope-filtered dispatch，确保监听器仅收到所属 agent 的事件。
- 注册表采用 `enter`（插入未公布条目）+ `announce`（发出 `agent/created`）的两阶段发布模式，并用 `announced`/`announcing`/`detachRequested` 三态标记保证并发创建下的唯一性与有序注销。
- 异步边界统一通过 `AbortController` 融合多来源取消（caller signal、owner fiber 卸载、factory teardown），并在 `prepare`/`resumeWith` 中以 `raceAbort`/`raceAbortCall` 包装 await 点，使 setup、load、publish 均可被同一信号中断。
- 配置项通过 `z.object(...).default(...)` 声明式校验，并在运行时通过 `installSettingsSection` 暴露为可热更新的 settings 段（如 `AGENT_LOOP_SETTINGS_SCHEMA`），getter 在每次调度时重新读取最新值。
- 工具调用执行遵循「模型顺序提交、结果顺序提交」约定：`executeToolCalls` 按 `planned` 顺序分组（exclusive/parallel），使用 `committed` 指针推进，只有连续完成的 slot 才会 commit 结果并追加 `additionalContexts`。
