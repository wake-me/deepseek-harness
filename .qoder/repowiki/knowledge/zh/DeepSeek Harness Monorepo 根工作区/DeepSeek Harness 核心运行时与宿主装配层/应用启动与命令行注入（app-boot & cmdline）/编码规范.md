- 每个包提供 `src/index.ts` 作为主 API 入口，并配套 `src/invariant.ts` 通过 `ctx.invariants.register(PACKAGE_NAME, install)` 注册包级不变量占位，形成统一的双入口模式。
- 对外暴露的类型通过 `package.json` 的 `exports` 字段显式声明，包括主模块与 `/invariant` 子路径，并在 `types` 字段指向 `lib/types/*.d.ts`。
- 所有外部依赖（cordis、loader、invariants、home-paths 等）均以 `workspace:^` 形式声明为 peerDependencies，保持包无运行时依赖、由宿主提供。
- 错误诊断统一采用 `${binName}: ...` 前缀格式，通过传入的 `binName` 参数在 load/parse 失败时输出带来源的可追踪消息。
- 配置文件与补丁文件解析统一使用 `js-yaml` 配合 `entryListSchema` / `userPatchesSchema` 进行强校验，解析失败直接抛出带文件路径的错误而非静默跳过。
- 对可选资源（`.env`、用户补丁文件）采用 ENOENT 即视为“不存在”的宽容读取策略，仅在非 ENOENT 错误时上报诊断。
