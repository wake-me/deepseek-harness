- 对外暴露的远程服务类继承 `TypertRemoteService`，通过静态 `inject` 数组声明依赖的服务键（如 `['loader']`、`['invariants']`）。
- 公共 API 通过 `@Remote('xxx')` 装饰器标记方法，将同步方法暴露为远程可调用的 RPC 接口。
- 跨包共享的类型集中在 `types.ts`，并使用 `Branded` 对字符串型 ID 做品牌化封装，而非裸字符串。
- Fiber 生命周期通过内部数值常量枚举映射到可读字符串阶段（pending/loading/active/failed/unloading/null），保持与 Cordis 内部 `FiberState` 常量的双向一致。
- 包内文件采用单一职责拆分：`index.ts` 暴露主服务、`types.ts` 集中类型、`invariant.ts` 作为独立的 invariant 伴侣模块，并通过 `package.json` 的 `exports` 字段分别发布。
