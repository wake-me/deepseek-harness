本模块以 Cordis Loader 为统一装配层，将 apiproxy、directory-picker（含 auto/browse/native 三种后端）、webserver、frontend-static、plugin-inventory 等子包作为独立插件加载：每个子包对外仅暴露一个 index.ts 入口与 invariant.ts 断言，由宿主在进程启动阶段按策略解析并挂载到共享上下文 ctx（如 ctx.apiProxy、ctx.directoryPicker、ctx.webserver）。apiproxy 作为核心网关承载所有领域 RPC，并通过 fetch/SSE 载体跨进程调用；directory-picker 族采用“抽象 seam + 自动探测”模式，auto 根据运行环境选择 browse 或 native 实现；webserver 提供 HTTP/Upgrade 路由，frontend-static 在其之上挂载 SPA 产物；plugin-inventory 则通过 Typert Remote 向可信方暴露当前非分组插件快照。各插件之间不直接互相引用，而是通过宿主注入的 ctx 或 apiproxy 暴露的远程接口进行协作。
