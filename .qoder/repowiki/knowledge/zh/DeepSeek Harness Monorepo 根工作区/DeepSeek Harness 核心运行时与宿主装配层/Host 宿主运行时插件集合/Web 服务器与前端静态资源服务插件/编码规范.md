- 每个插件通过 `package.json` 的 `exports` 字段分别暴露根入口和 `./invariant` 子路径，并将编译产物输出到 `lib/` 目录。
- 配置对象使用 `@deepseek-ai/schemastery` 的 `z.object({...}).required()` 模式定义，并以同名 `Config` 常量导出供外部校验。
- 对外暴露的注册 API（`register`、`registerUpgrade`、`registerFallback`、`tapIndex`）统一返回一个 disposer 函数用于移除自身，遵循可组合的资源管理模式。
- 错误处理采用 per-request 捕获：HTTP 处理器 catch 后记录日志并返回 400，升级 socket 的错误监听在 close 时清理，保证单个坏请求不会终止进程。
- 插件通过 Cordis 的 `Service` 基类与 `effect` 钩子管理生命周期，在服务初始化时启动监听，在 effect 回调中执行优雅关闭。
