模块由两个相互依赖的 Cordis 插件组成，形成清晰的层次：
- `packages/host/webserver`（@deepseek-ai/dsh-host-webserver）：核心网关层，导出 `WebServer` Service，内部维护 `exact`、`prefixes`、`upgrades` 三个路由表和一个单例 fallback handler；通过 `register`/`registerUpgrade`/`registerFallback`/`tapIndex` 暴露扩展点，在 `[Service.init]` 中创建 `node:http` Server，按 exact → longest-prefix 顺序匹配请求，未命中时交由 fallback 或返回 404；同时监听 `upgrade` 事件处理 WebSocket 等长连接，并在关闭时显式销毁已跟踪的 upgraded sockets。
- `packages/host/frontend-static`（@deepseek-ai/dsh-host-frontend-static）：消费层插件，声明 `inject = ['webServer']`，通过 `apply(ctx, config)` 调用 `ctx.webServer.registerFallback` 认领 fallback seat，实现 `serveStatic` 函数完成路径规范化、目录穿越拒绝（403）、已知扩展名 MIME 映射、未知扩展以 octet-stream 输出、以及 ENOENT/EISDIR 回退到 index.html 的 SPA 路由语义；所有 index.html 响应经 `ctx.webServer.applyIndexTaps` 注入 boot-manifest。
- 依赖方向单向：frontend-static → webserver，webserver 不感知任何前端概念，仅暴露纯 HTTP 路由契约；两者均通过 `@deepseek-ai/schemastery` 定义配置 schema，并通过 `@deepseek-ai/cordis` 的 Service/effect 机制管理生命周期。
