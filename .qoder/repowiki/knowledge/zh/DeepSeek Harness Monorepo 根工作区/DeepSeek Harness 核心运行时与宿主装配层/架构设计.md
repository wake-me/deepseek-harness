本模块按职责分层组织：util 提供零依赖原语（原子写、超时、品牌类型等），core 基于这些原语实现 Agent Loop、Session、Scope、Tools、System Prompt 等运行时能力；boot 负责 .env/Loader/快照解析并将命令行参数注入 Cordis 上下文；host 通过 apiproxy、directory-picker-*、webserver、plugin-inventory 等可插拔插件暴露宿主能力。启动链路自上而下为：dsh 二进制 → boot/app-boot 加载配置文件与用户补丁 → 通过 Cordis Loader 注册 host 插件 → 由 core 的 agent-loop/session/tools 组合成完整 Agent 运行时 → 经 host/apiproxy 以 RPC schema 暴露给前端/Harness 客户端。跨子包的契约集中在 core 各子包的 index.ts 导出与 host/apiproxy 的 *.schema.ts + *.ts 配对中，util 被 core 与 host 共同消费但不反向依赖。
