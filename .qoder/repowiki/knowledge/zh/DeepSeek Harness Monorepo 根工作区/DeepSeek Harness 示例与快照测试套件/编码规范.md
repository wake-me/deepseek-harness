- 每个示例以独立的 `cordis.yml` 声明插件树，并通过 `!!js` 表达式读取 `DSH_*` 环境变量实现运行/快照双模式切换。
- 快照用例统一采用 `<scenario>/input.json` + `session.jsonl` + `stdout.expected.jsonl` 的三件套结构，必要时附加 `system-prompt.expected.md` 与 `tool-schemas.expected.json`。
- e2e 测试通过 `launchAcpTestAgent`/自定义 harness 启动真实子进程，并在 `afterEach` 中调用清理函数释放进程与工作目录。
- 需要真实 API Key 的用例通过 `describe.skipIf(!process.env.DEEPSEEK_API_KEY)` 条件跳过，保证无凭据时 CI 仍可通过。
- 沙箱权限通过 `DSH_PERMISSION_MODE` 在 `danger-full-access` 与 `workspace-write` 间切换，快照用例默认启用全访问以保证 runner 无关性。
- 子示例之间保持解耦，仅通过 workspace 依赖引用 `@deepseek-ai/dsh-*` 包，不在示例间互相 import。
