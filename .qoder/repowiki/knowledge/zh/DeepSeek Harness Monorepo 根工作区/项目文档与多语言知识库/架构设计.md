文档按职责分层组织：根目录存放全局性说明（architecture.md、development.md、glossary.md、config/tool/persistence-catalog.md 等）；subsystems/ 为每个子系统提供一对中英参考页，描述类型定义、语义与生成的 Cordis API；cordis-tutorial/ 与 cordis-api/ 分别提供分步教程与 API 参考；user/ 面向最终用户，分为 guide/ 与 develop/ 子目录；cookbook/ 收录编号验证的实操步骤；postmortem/ 以编号文件记录事故复盘；i18n/ 集中翻译规则与术语约定。每篇 Markdown 均配套 .i18n.yaml 清单与 .zh.md 中文镜像，通过 `dsh-translate-docs` 与 `verify-translation-pairing` 工具维持成对一致性。AGENTS.md 作为文档标准，规定层级归属、字数预算（由 scripts/doc-budgets.manifest.json 约束）、代码块编译校验与链接检查等质量门禁。
