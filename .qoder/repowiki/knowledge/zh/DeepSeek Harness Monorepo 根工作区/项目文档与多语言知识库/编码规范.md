- 每篇文档采用英文主文件 + .i18n.yaml 清单 + .zh.md 中文镜像的三件套结构，中文侧通过配对工具保持同步。
- 文档严格遵循 AGENTS.md 的层级分类：架构概览放 architecture.md，类型与语义放 subsystems 对应页面，操作步骤放 cookbook，产品指南放 user/，事故复盘放 postmortem/。
- 教程类文档使用编号化的 verify 步骤，使读者可逐项执行并验证结果。
- 所有跨仓库引用使用相对 Markdown 路径而非裸文件名，以便 verify-md-links 检测死链与缺失片段。
- Fenced ts 代码块必须可编译，公开类型声明使用 public-api 或 type-equiv 标记并在清单中注册以防漂移。
- postmortem 文件以四位序号命名（如 0001-xxx.md），并以 Executive summary 开头，随后展开 Summary / Timeline / Root cause / Guardrails 章节。
