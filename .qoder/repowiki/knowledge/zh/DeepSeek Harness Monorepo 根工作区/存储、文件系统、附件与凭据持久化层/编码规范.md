- 每个子域拆分为「types-only 包 + 具体实现包」，实现包通过继承或实现对应抽象类/接口来接入，类型包不引入运行时依赖。
- 对外标识符一律使用 `Branded<'Name'>` 字符串品牌（如 `FsTargetKey`、`FsVersion`、`CredentialRef`、`AttachmentId`）防止误用。
- 所有写操作通过 Promise 链串行化（`chain.then(job).then(noop, noop)` 或 per-target lock map），确保并发安全且不会因单个失败中断后续任务。
- 错误采用带稳定 `code` 字段的自定义 Error 子类（`FsError`、`AttachmentError`、`DomainError`、`StorageError`），由上层按 code 分支而非消息匹配。
- Cordis 插件通过 `static Config = z.object(...)` 声明配置 schema，并在 `apply(ctx, config)` 中调用 `ctx.effect` 返回 disposer 完成资源释放。
- 持久化写入采用原子发布模式：先写临时文件再 rename/link，必要时对目录 fsync 以保证崩溃恢复一致性。
