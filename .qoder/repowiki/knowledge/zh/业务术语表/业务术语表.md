### Harness home
- 定义：用户级定制目录，默认路径为 `~/.dsh`，存放 `cordis.patch.yml`、`profiles/`、`skills/` 等用户自定义配置与扩展，是官方推荐的“不改源码”定制入口。
- 别名：DSH_HOME、~/.dsh

### 组合包（bundle）
- 定义：dsh 的配置 + 挂载代码的分发格式，通过 `cordis.yml` 声明要加载的插件集合；用户可用 `dsh --profile web --dump-config` 查看实际配置树，任何条目均可被自己的 patch 替换。
- 别名：bundle、cordis.yml

### 能力 seam
- 定义：dsh 的核心架构概念：一项完整能力必须由 Service Definition（接口声明）、Service Provider（实现）、Consumer（通常是面向模型的工具）三件套组成；更换 provider 即可改变整个产品行为（如把 fs/shell 指向 E2B 远程沙箱）。
- 别名：seam、三角色设计模式

### 会话事件日志
- 定义：dsh 的唯一事实源（single source of truth），记录所有抵达模型的请求与工具调用；fork、恢复、transcript、遥测、UI 全部从该仅追加事件流派生，核心不变量为“模型可见 = 已记录”。
- 别名：session log、event log

### 轮次/步骤模型
- 定义：dsh 的基本执行单元：turn（轮次）包含 step（步骤），每个 step 是一次模型请求加上它调用的工具；关键扩展点包括 `agent/pre-step`、`agent/request`、`llm/stream`、`tools/*` 等 waterfall 事件。
- 别名：turn、step

### 开发者预览
- 定义：项目当前状态（`0.1.0-rc.5`），明确声明未来会有破坏性变更，连磁盘格式都不保证兼容；因此跟随官方更新需小步勤跑，避免长期积累导致合并困难。
- 别名：developer preview、rc

### Agent Notes
- 定义：位于 `.agents/notes/` 的架构决策记录体系，所有非平凡变更必须附带一份 Agent Note，归档后冻结；整个仓库围绕“AI agent 参与开发”设计，`AGENTS.md` 与 `CLAUDE.md` symlink 即为此目的。
- 别名：.agents/notes、架构决策记录

### dsh-plugin
- 定义：社区生态标签，第三方插件仓库应添加 `dsh-plugin` GitHub topic 以便被发现；插件以独立 npm 包（组合包）形式发布，通过 profile 安装。
- 别名：dsh plugin
